Todos os programas abaixo podem ser executados em compiladores online, uma vez que não fazem import de bibliotecas.  

# Ajustando-Votos
Programa destinado a auxiliar na organização de eleitores.   
O programa exige a seguinte estrutura:<br/>
<br/>
Título de Eleitor:  
[Título] | Zona: [Num] | Seção: [Num]  
[CPF]  
[Data de Nascimento]  
[Nome]  

**Legenda**  
[texto]: O texto digitado aqui é referente a informações alteradas a cada registro  

# Contador de Votos  
O programa faz a leitura de 2 entradas, sendo o texto a encontrar (busca exata) e os votos (não necessariamente organizados).  
Após ambas as entradas, faz a contagem e exibe o resultado.  

# ZonasCPF  
Nesse programa serão pedidos os votos. O programa recolherá e exibirá o início de cada CPF, sem repetir, em uma tabela de 6 colunas máximas.

** **Em todos os programas é necessário digitar "sair" para finalizar o programa** **
